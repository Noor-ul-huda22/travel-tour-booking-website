# Safarnama Tours - Travel & Tour Booking Website

A 3-page travel website built with React and Vite as a Devlattice Systems
frontend portfolio project.

## Pages
- Home (/)
- Tours (/tours)
- Booking (/booking)

## Tech
React, Vite, JavaScript (JSX), plain CSS, react-router-dom

## How to run
1. npm install
2. npm run dev
3. Open the link shown in the terminal (usually http://localhost:5173)

## Build
npm run build
